# 强教师几何准备

## 已实现

由旧提取/拟合代码复制到新名称后扩展，原文件保持不变：

1. 同一真实 RGB 和 VACE metadata 的标注派生人框，执行完整 SAM3D body 前向。
2. 保存 MHR 网格（米）、相机、关键点和 pooled RGB，检查实际图像、crop、UID、相机重投影与 SHA。
3. 使用官方 MHR→SMPL 的三角形/重心坐标表面映射，随后独立 Adam 400 步拟合 SMPL。
4. 只把教师网格与 HMR 预测初值传入优化，不按 GT 误差筛选；拟合平移不替换原 crop camera。
5. 按 train 和 validation 分开处理；完整计划分别为 22,735 与 10,413 人帧，未提取 test。

## 当前结果与失败记录

新提取器完成固定 64 帧真实预测，并通过图像/历史 SHA/网格/相机比较。旧元数据没有逐行 SHA，控制器 v1 失败后，v2/v3 改用此前冻结拟合报告中的真实历史 SHA。米与像素的误差采用不同单位阈值，保留差异诊断。

GPU2 后来被另一任务占用；在核对本项目训练 PID、显存和主机内存后，v5 与 V30 共用 GPU1。64 帧新拟合完成，但 rotmat 参数逐元素 `allclose` 检查失败，流程停止。

因此：**当前没有完整教师缓存，没有教师 validation 成绩，没有蒸馏训练结果。** `launch_geometry_teacher_v30_v5.py` 保留的是最后运行过的失败版本，不是可直接宣称成功的发布流程。
